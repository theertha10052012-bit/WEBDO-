    Import Data

    Add or update many products at once from a CSV file. The first row must be the header: name, category, barcode, quantity, minimum, target.

    Choose a file

    Only .csv files up to 1 MB. Columns must be separated by commas. In Excel, save as "CSV UTF-8".

    If a barcode already exists, that product is updated. If a row has no barcode, it is matched by product name (upper or lower case does not matter). Otherwise a new product is added.

    Choose a CSV file to see a preview. Nothing is imported until you click "Import valid rows".
